## 9. 减少动态效果 [已验证]

在 `prefers-reduced-motion: reduce` 生效时：

- `--motion` 解析为 `0`，全部过渡时长为 `0s`
- `document.getAnimations().length === 0`
- 三个氛围消费方（背景光晕、网格视差、进度条）`animation-name` 全部为 `none`
- JS 不设置 `data-reveal`，因此唯一的「默认隐藏」规则不生效，全部正文可见
- 平滑滚动改为 `auto`（`scroll-behavior` 刻意不在 CSS 设置，只有一处配置）

`?motion=off` 与运行时 `document.documentElement.dataset.motion = 'off'` 两条
可测试路径与真实用户偏好收敛到同一个开关。

动效开启时的时序核对：首屏标题 360ms 内全部可读；工作流三段流动高亮合计 1200ms、
`iteration-count: 1`、`fill-mode: backwards`（播完回到不可见的基础态，静态图完整）；
正文显现 240ms + 12px。
